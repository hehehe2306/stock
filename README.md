台股大戶籌碼週報 Agent（初步構想）
課程單元 0 練習：用 AI Agent 平台規劃一個能真的解決自己需求的助手雛形——每週自動整理台股大戶籌碼增減排行，取代自己每週手動查表比對的麻煩。

動機
每週想知道「這週哪些股票大戶在加碼、哪些在出貨」，目前只能自己去集保結算所網站查股權分散表，再手動跟上週的數字比對、排序，很花時間也容易漏看。這個 Agent 的目標是把「抓資料 → 比對上週 → 排行前十名 → 整理成看得懂的週報」整套流程自動化。

資料來源與定義（初步假設，待確認/調整）
資料來源：台灣集中保管結算所（TDCC）「集保戶股權分散表」，每週固定公布一次，屬官方公開資料。
「大戶」定義：暫定為持股 1,000 張以上 級距的股東，觀察其占該股票發行股數比例的週增減（這個門檻之後可能依實測調整，例如改看 400 張以上）。
「增加/減少前十名」：以全部上市櫃個股為範圍，依大戶持股比例的週變動幅度排序，分別列出增加最多、減少最多的前 10 檔。
使用場景
場景	情境	Agent 處理方式
每週例行查詢	集保結算所公布本週股權分散表後	自動抓取當週資料，與上週資料比對出大戶持股比例變化
排行整理	       想知道這週該注意哪些股票	  依變動幅度排序，輸出增加前十名、減少前十名兩份清單
週報回顧	       想追蹤某檔股票的籌碼趨勢	  保留歷史週資料，之後可查詢特定個股近幾週的大戶持股變化
免責提醒	           每次輸出排行結果	    附上「僅為籌碼面公開資料整理，非投資建議」提醒，避免誤導
後續規劃
單元 4（Knowledge）：把每週抓到的股權分散表資料存成可查詢的歷史知識庫，才能做「近幾週趨勢」查詢
單元 5（Plugin-Tool）：串接集保結算所資料抓取（爬蟲或既有 API），取代手動查表
單元 6–7（Workflow）：排成每週固定執行的批次流程（抓資料 → 比對 → 排序 → 產出週報）
單元 8（Guardrail）：確保輸出只陳述籌碼面公開數據事實，不做加碼/減碼的投資建議
